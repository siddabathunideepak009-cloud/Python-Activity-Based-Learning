\# Python Activity-Based Learning



\## Project Overview

This repository contains 10 Python case studies developed as part of Python Activity-Based Learning. Each case study demonstrates programming concepts through a practical problem, algorithm, pseudocode, Python implementation, and sample execution.



\## Case Studies



| No. | Case Study | Folder |

|---|---|---|

| 1 | Multi-Currency Travel Budget Analysis | `Case\_Study\_09\_Currency` |

| 2 | ATM Transaction Sequence Simulation | `Case\_Study\_13\_ATM\_Sequence` |

| 3 | Smart Parking Fee Management | `Case\_Study\_15\_Parking` |

| 4 | Multi-Day Water Tank Simulation | `Case\_Study\_16\_Water\_Tank` |

| 5 | Password Policy Validation Engine | `Case\_Study\_29\_Password` |

| 6 | String-Based Examination Answer Evaluation | `Case\_Study\_31\_Exam\_Evaluation` |

| 10 | Multi-Product Price Fluctuation Analysis | `Case\_Study\_63\_Price\_Fluctuation` |



\## Technologies Used

\- Python 3

\- Visual Studio Code

\- Windows PowerShell



\## How to Run

1\. Install Python 3.

2\. Open this project folder in Visual Studio Code.

3\. Open the integrated terminal.

4\. Run the required case study using the `py` command.



Example:



```powershell

py Case\_Study\_09\_Currency/main.py

```



Replace the folder name with the required case study folder to run another program.
